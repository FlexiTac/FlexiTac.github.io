    FPC arrangement

    The connector side applies to both boards and turns each whole board. Scan order assigns channels to connector pins (pin 1 is marked in the previews); neither moves copper on the board.

    Connector size

    Leave empty for one contact per channel. A larger ZIF connector adds isolated NC contacts at the unused positions.

    Fan-out traces

    The traces leave the sensor thin, run as a tight bundle and widen again at the gold fingers.

    Diagonal: each row trace runs as a slant from its row's end beside the field, so the board is narrowest at the tip; both boards share one outline down to their tails, which leave one bottom edge, stacked (the Row tail on the centred Column tail; they part to their own connectors). With both sides the Row pins fold (ROW_01, 03, …, 04, 02). It is built with Gen by Surface's rules (0.5 mm field margin, up to 64 columns, tails from 7.5 mm). Straight channel: the row traces run in one channel beside the field, the Row pins in order (up to 32 columns, tails from 7.0 mm).

    Ordering notes

    Step by step: the FlexiTac fabrication guide.

    Gerber ZIPs are deterministic Direct Gerber / JLC review candidates: upload top and bottom separately, then verify the outline, the coverlay openings and the PI stiffener listed under Standardized manufacturing. They are not EasyEDA-native exports and are not production approval. The EasyEDA Pro projects ZIP holds one native .epro2 project per board: import it into EasyEDA Pro (pro.easyeda.com, File > Import > EasyEDA/JLCEDA (Professional)), check FPC mode, the stiffener and DRC there, and let EasyEDA write the Gerbers and the order (README_EASYEDA.txt). Every file name starts with the build id. The design and layout JSON downloads are readable copies of the shown build; the project review ZIP carries their canonical, byte-stable versions.
