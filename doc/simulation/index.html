Tactile simulation

Simulate FlexiTac pads in NVIDIA Isaac Sim, then replay tactile trajectories and record visuo-tactile demonstrations in the browser. Plus VT-Refine, the sim fine-tuning research behind it.

The simulation lets you work with touch without any hardware. Simulated pads give the same 12 × 32 taxel grid as a FlexiTac-V2 sensor, on the fingers of a robot in NVIDIA Isaac Sim. The current release is the FlexiTac tactile simulation in Isaac Sim, which this page shows you how to build and run. It uses the same bimanual plug–socket setup and the same pad layout as VT-Refine, the research on fine-tuning visuo-tactile policies in simulation, whose own code runs on the older Isaac Gym.

#Build the Isaac Sim simulation

The repository is an Isaac Lab tree with two additions: a tactile sensor for FlexiTac pads, and an ALOHA environment whose four fingers each carry a simulated pad.

You need: a Linux x86_64 computer (Ubuntu 22.04 or newer) with an NVIDIA RTX GPU and a driver of version 580.65 or newer, plus git and uv↗. Isaac Sim, PyTorch and Isaac Lab take about 30 GB. The trajectory viewer opens a desktop window; the browser interface can run headless. No FlexiTac hardware is needed.

#Replay a trajectory with touch

Replay an episode from the bundled sample dataset. The ALOHA robot repeats the recorded motion, and a separate window shows the four finger pads as live tactile heatmaps.

The script really is named reply_with_tactile.py. Change --episode_idx to replay another episode, and add --headless to run without the Isaac Sim window.

#Teleoperate and record in the browser

Start the web interface, then open http://localhost:8080:

Drag the handle on each end effector to move the two arms, and open or close each gripper with its buttons. The page shows the four tactile heatmaps, the simulated camera and the robot state as you work. Reset puts the plug and socket back at the start with a slightly randomized wrist orientation.

Start Recording and Stop Recording save each demonstration as one .npz file in Isaacsim_tactile_env/output/trajectories/. Each file holds:

#How the simulated pad works

Each finger has a pad with a 12 × 32 grid of taxels at 2 mm pitch, the same layout as a FlexiTac-V2 sensor. On every step, NVIDIA Warp↗ measures how far each taxel has pushed into the object's mesh. That depth becomes a spring force, clamp(stiffness × depth, 0, max_force), which is then divided by max_force so each reading lies between 0 and 1. The taxels sit 1.4 mm in front of the pad's face, so a reading starts just before the object touches it; lower normal_offset (or pass --normal_offset to either script) for smaller contact patches. The grid size, spacing, normal_offset (0.0029 m from the pad's mid-plane), stiffness (5000) and max_force (10) are settings in AlohaTactileEnvCfg↗.

What it does not model yet

  • The pads on the left arm sense only the socket, and the pads on the right arm only the plug. Touching anything else, such as the table, gives no signal.
  • Readings are normalized from 0 to 1, not calibrated to a real sensor's output.
  • The environment is built around the ALOHA robot. Using another gripper or pad layout means changing the code; there is no guide for that yet.

#VT-Refine

VT-Refine↗ (CoRL 2025) trains bimanual assembly policies in three stages, from real to sim and back to real. It first trains a diffusion policy on about 30 real demonstrations per task. Each demonstration records FlexiTac pads on all four fingers together with a camera point cloud, the representation from 3D-ViTac. Next it fine-tunes that policy in a simulated copy of the setup with large-scale, GPU-parallel reinforcement learning. Finally it moves the policy back to the real robot. The tasks are plug–socket insertions done in mid-air.

The repository has the simulation and training side: a Docker environment, the simulated environments with their tactile model, training configs, and a script that downloads about 909 MB of pre-training data. It does not include trained checkpoints or code for collecting data or running on a real robot.

  1. Install with Docker

    Clone with submodules and build the image, which installs the TacSL build of Isaac Gym. README: Installation↗

  2. Pre-train the visuo-tactile policy

    Download the data and train the diffusion policy. README: Pre-training↗

  3. Fine-tune in simulation

    Evaluate the pre-trained policy in simulation, then fine-tune it with reinforcement learning. README: Evaluation↗ · Fine-tuning↗
